# Urban Mobility Simulation

We simulate shared mobility services (e.g. ride hailing, vehicle sharing), the infrastructure they use (e.g. charging), and the markets that link them to users (e.g., Mobility-as-a-Service) and to each other (e.g. charging slot auction).
